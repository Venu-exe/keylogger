# Keylogger

> For educational purposes only. Use only on your own system.

## Requirements
pip install pynput termcolor pyfiglet

## Usage
python3 keylogger.py

## Features
- Records all keystrokes
- Mouse click logging
- Timestamp on each key
- Key counter
- Saves to keylog.txt
- ESC to stop
